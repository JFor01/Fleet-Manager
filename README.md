<p>Fleet manager is a minimal fullstack application where 
you can synchronize your drivers and cars from the admin poin of view. <p>

<p>You can plan, start and finish trips while the app automatically
manages availability of drivers and cars. This means 
that it is impossible to start a trip with a busy driver or a car already in use</p>

<p>This app is only a MVP prototype and require
addition of many more features such as ading new cars and drivers through interface.</p>

<p>Backend is managed by spring while frontend is managed by angular.</p>

<p>You can use docker compose up --build to run this via docker on 
default port 80
</p>

<p>
Alternatively you can run gradle bootRun for backend 
and npm star for frontend with the app exposed on port 4200
</p>
